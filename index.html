Project Overview

This project focuses on analyzing e-commerce product data collected from Flipkart. The dataset contains product details such as product names, categories, brands, prices, discounts, ratings, review counts, seller information, and delivery details where publicly available.

The purpose of this project is to understand product pricing, discounts, customer ratings, and brand performance through data analysis and visualization.

Conclusion

This project demonstrates how Excel, Python, SQL, and Power BI can be used to organize, clean, analyze, and visualize e-commerce product data. The analysis helps identify product trends and present useful business insights.

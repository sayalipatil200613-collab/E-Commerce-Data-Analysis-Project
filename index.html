1. Project Overview

This project analyses e-commerce product data collected from Flipkart to understand prices, brands, ratings, reviews and discounts.

Objectives

  • Analyse product prices and discounts.
  • Compare brands and customer ratings.
  • Identify popular products using review counts.
  • Perform data cleaning and exploratory data analysis.
  • Create an interactive Power BI dashboard.

Technologies Used

Microsoft Excel, PostgreSQL, SQL, Python, Pandas and Power BI.

2. Data Cleaning & Preprocessing

  • Checked missing values.
  • Identified duplicate records.
  • Checked and corrected data types.
  • Reviewed product names and categories for consistency.
  • Prepared data for analysis.

3. SQL Analysis – PostgreSQL

Sample queries used for product analysis.

Display All Products

SELECT *
FROM ecommerce_products1;

Total Products

SELECT COUNT(*) AS total_products
FROM ecommerce_products1;

Average Product Price

SELECT ROUND(AVG(price), 2) AS average_price
FROM ecommerce_products1;

Products by Brand

SELECT brand, COUNT(*) AS product_count
FROM ecommerce_products1
GROUP BY brand
ORDER BY product_count DESC;

Highest Rated Products

SELECT product_name, brand, price, rating
FROM ecommerce_products1
WHERE rating IS NOT NULL
ORDER BY rating DESC
LIMIT 10;

4. Python – Exploratory Data Analysis

Python and Pandas are used to inspect the dataset, check missing values and analyse product prices.

import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("ecommerce_products.csv")

print(df.head())
print(df.info())
print(df.isnull().sum())
print(df.duplicated().sum())
print(df.describe())

df["price"].plot(kind="hist")
plt.title("Product Price Distribution")
plt.xlabel("Price")
plt.show()

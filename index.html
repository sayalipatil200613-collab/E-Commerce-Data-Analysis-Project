E-Commerce Product Price & Review Analysis

Welcome to my E-Commerce Data Analysis Project.

Project Overview

This project analyses product prices, brands, ratings, reviews, and discounts using Flipkart data.

Technologies Used

Excel, PostgreSQL, Python, Power BI

Project Objectives

  • Analyse product prices and discounts.
  • Compare brands and customer ratings.
  • Perform data cleaning and EDA.
  • Create a Power BI dashboard.
